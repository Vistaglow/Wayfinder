6. Filter

Placeholders

  • {param}: the value of a parameter. Clauses whose placeholders are all empty are left out.
  • {user_sys_id} or javascript:gs.getUserID(): the user asking.
  • {namesearch:param:f1,f2}: name search that ignores word order (each word must match one of the fields).
  • {query} with "Raw query" ticked: passes a model-written sysparm_query through, ANDed with the rest.

The AI's values are cleaned: ^, line breaks and javascript: are removed, except in raw-query parameters (which may only use date helpers).
